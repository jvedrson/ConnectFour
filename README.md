# Connect Four : .NET Software Development

A simple project featuring the classic game **Connect Four**, developed using **Blazor** and **C#** for the **CSE 325** course.

## Description

This web application allows two players to enjoy a game of Connect Four in the browser, taking turns and automatically validating win or draw conditions.

## Features

- **2-Player Mode:** Alternating turns between Player 1 and Player 2.
- **Color Customization:** Interactive color picker for each player's tokens and the board background.
- **Winner Detection:** Automatic validation of 4-in-a-row sequences (horizontal, vertical, and diagonal).
- **Draw Detection:** Identifies when the board (42 slots) is full without a winner.
- **Game Reset:** Button to restart the game after it ends.

## How to run the project

1. Install the [.NET SDK](https://dotnet.microsoft.com/download) (.NET 10 version or compatible)
2. Clone or open the project folder in your terminal
3. Run the command: `dotnet run` (or `dotnet watch`)
4. Open the URL indicated by the console in your browser
